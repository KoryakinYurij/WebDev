# Линия сгиба — автономный скролл-сайт

Вымышленная мастерская бумажных объектов. Один документ: смысл, навигация и главное
действие работают без JavaScript; скрипт только добавляет сцену и переключатели.

Runtime-зависимостей нет: ни фреймворка, ни сборщика, ни внешних шрифтов, фотографий и CDN.
Node нужен только для сборки одного файла и проверок.

## Быстрый запуск

```sh
cd "Test 2"
node build.mjs             # собрать автономный dist/index.html
```

Готовый файл открывается двойным щелчком: `dist/index.html` не обращается к сети.
Исходный `index.html` тоже открывается напрямую из файловой системы, потому что
скрипт подключён как обычный (не `module`).

Локальный сервер для просмотра из каталога проекта — любой статический:

```sh
python3 -m http.server 8000     # затем откройте http://localhost:8000/
```

## Проверки

```sh
cd "Test 2"
npm run check              # сборка + статические проверки, отчёт в checks/static-report.txt
npm run figures            # текстовое превью геометрии SVG (браузер не нужен)
```

`node scripts/check.mjs` разбирает разметку и стили, считает контраст по формулам WCAG 2.2,
сверяет `dist/index.html` с исходниками, проверяет границы геометрии фигур и запускает чистые
функции `main.js` в Node. Код возврата 1, если что-то провалено.

Браузерных проверок в скрипте нет намеренно: они требуют реального браузера и остаются делом
ручного просмотра; отчёт скрипта их не подменяет. Что именно удалось увидеть в браузере, а что
нет — раздел 5 и раздел 6 в `REPORT.md`.

Как посмотреть самому: откройте `dist/index.html` двойным щелчком или через превью-панель,
прокрутите раздел «Три состояния листа» вниз и назад, нажмите обе кнопки. Системное уменьшение
движения переключается в настройках системы; если браузер встроен в панель и настройка ОС не
переключается, её значение можно подменить до запуска `main.js` (`matchMedia`, как в инструментах
разработчика) — так была проверена таблица режимов из `REPORT.md`.

## Состав

| Файл | Роль |
| --- | --- |
| `index.html` | вся разметка и содержание; пять inline SVG; якоря и подписи |
| `styles.css` | токены, макет, закреплённая сцена, состояния схемы, режимы движения |
| `main.js` | прогрессивное улучшение: сцена, кнопка сгиба, уменьшение движения |
| `build.mjs` | сборка `dist/index.html` без внешних ссылок (стандартная библиотека Node) |
| `scripts/check.mjs` | статические проверки и отчёт `checks/static-report.txt` |
| `scripts/preview-figures.mjs` | печать фигур символами: единственный обзор геометрии без браузера |
| `TASK.md` | задание, выбранные инструменты и отличия от пакета для Prism |
| `REPORT.md` | что проверено, что нет, какие источники помогли, чего не хватило |
| `dist/index.html` | результат сборки (генерируется, но лежит в проекте для сдачи) |
| `checks/static-report.txt` | последний отчёт проверок (генерируется) |

## Состояния страницы

- **Без JavaScript.** Читается весь рассказ, работает навигация и главное действие;
  три состояния листа показаны тремя статическими кадрами; схема описывается статически;
  кнопки, которые включает скрипт, остаются скрытыми (`[hidden]`), чтобы не было
  неработающих элементов управления.
- **JavaScript, обычное движение.** Раздел «Три состояния листа» закрепляется на широком
  экране (≥ 62rem и высота окна ≥ 560 px): кадр меняется по положению прокрутки, обратная
  прокрутка возвращает прежние стадии. Кнопка «Показать сгиб / Вернуть плоскость»
  управляет отдельной схемой. Если кадр перестаёт помещаться (окно стало ниже, сцена выросла),
  закрепление снимается повторной проверкой вместимости при изменении размера окна; на
  подходящем окне оно включается снова.
- **Уменьшение движения.** Эффективное уменьшение = системная настройка ИЛИ ручной
  переключатель в шапке. В этом режиме закрепление выключено, все три кадра показаны
  статически, состояния схемы меняются мгновенно, прокрутка нативная, смысловые действия
  работают. При включённой системной настройке переключатель заблокирован и объясняет это:
  системное предпочтение не отменяется. Смена режима в середине рассказа не сбрасывает место
  чтения: стадия, на которой вы находитесь, остаётся на той же высоте экрана.
- Выбор ручного режима запоминается в `localStorage` (`fold-line.motion`); при запрете
  хранилища страница работает так же, только без памяти между загрузками.

## Правки

- Содержание и структура — `index.html`; текст из брифа использован дословно.
- Цвет, шрифтовые роли и ритм — токены в начале `styles.css`.
- Геометрия схемы листа — атрибуты `points`/`d` в `index.html`; после правки запустите
  `npm run check` (проверки G01–G08 следят за связностью сгиба и подъёмом) и `npm run figures`.
- Правила поведения — `main.js`; чистые функции покрыты проверками `L01` (стадии, подписи,
  переключение сгиба) и `L02` (четыре сочетания системного и ручного уменьшения движения,
  формулировки заметки). Изменения раскладки сцены сходятся в одну точку — `syncScene()`.
