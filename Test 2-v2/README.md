# «Линия сгиба», версия 2

Автономная страница-рассказ: один лист бумаги меняет форму вместе с прокруткой.
Без зависимостей, без сети, без сборщика — только Node 18+ для проверок.

* `index.html`, `styles.css`, `main.js` — исходники; `dist/index.html` — тот же
  материал одним файлом, открывается по `file://`.
* `npm run check` — сборка, запись прокрутки и 43 проверки.
* `npm run film` — `checks/film.html`: 75 кадров сцены и проигрыватель с ползунком.
* `npm run frames` — кинолента символами в терминале: `node scripts/frames.mjs stage 96`.

Что происходит на странице: лист лежит на столе, из него печатается заголовок
(та же перспектива, что у рисунка), прокрутка поднимает половину листа до вертикали,
переводит её в тень и закрывает лист поверх заголовка. Ход обратим. На узком экране
лист занимает верх сцены, рассказ встаёт под ним. При уменьшенном движении — системном
или ручном — лист стоит на одном кадре, а рассказ читается подряд с тремя статическими
кадрами; место чтения при смене режима сохраняется.

Подробности, референсы, замеры в браузере и честный список того, что не проверено, —
в [REPORT.md](REPORT.md). Первая версия страницы лежит рядом, в папке `Test 2`.
