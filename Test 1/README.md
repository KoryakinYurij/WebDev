# MINDFIELD

Сайт об интенсивной практике внимания. Сделан как **тест подхода**: сначала из проверенных
репозиториев-референсов вытаскиваются только те решения, которые реально влияют на код,
и уже из них собирается проект. Не «вдохновлялся списком ссылок», а «прочитал правила,
применил, отклонившееся — задокументировал».

Задача страницы: медитация **без дыхательных таймеров и без интонации «расслабься»** —
кинетический, насыщенный скролл-опыт с интерактивом и несколькими видами скролл-анимации.

## Запуск

```bash
npm install
npm run dev        # генерация токенов + vite dev server
npm run typecheck  # tsc --noEmit
npm run build      # токены + typecheck + прод-сборка
npm run tokens     # только пересборка токенов
```

## Что откуда взято

Полный разбор решений с обоснованиями — в [`docs/DESIGN-CODEX.md`](docs/DESIGN-CODEX.md).
Коротко:

| Референс | Что взяли |
|---|---|
| `ai-web-design-codex` | правила scroll-driven опыта, бюджеты motion, перф-дисциплина, a11y |
| `design-tokens/community-group` | формат DTCG как источник правды по токенам |
| `awesome-design-systems` | слои «токены → примитивы → секции» |
| `motion-primitives` | магнитные кнопки, `layoutId`-переходы, spring-микровзаимодействия |
| `awesome-web-animation` | карта инструментов, эффект «расшифровки» текста, velocity-маркиза |
| `three.js` | один signature-момент: шейдерный фон + облако точек |
| `Front-End-Performance-Checklist`, `inclusive-design-checklist` | перф- и a11y-гейты |

Сознательно **не** взяли: Lottie (1400+ DOM-узлов на анимацию), anime.js (нет реактивного
жизненного цикла), mojs, ScrollMagic/Locomotive (legacy), постпроцессинг в WebGL
(полные проходы на кадр), «анимированные счётчики 0 → 150 243» (анти-паттерн из кодека).

## Архитектура

```
tokens/design.tokens.json     источник правды (DTCG)
scripts/build-tokens.mjs      без зависимостей → tokens.css (@theme для Tailwind v4) + tokens.ts
src/generated/                ← генерируется, руками не править

src/styles/tokens.css         @theme: bg-*/text-*/font-*/ease-* утилиты появляются автоматически
src/lib/motion-config.tsx     MotionProvider: системный reduced-motion + ручной тумблер + качество
src/lib/smooth-scroll.tsx     Lenis, подключённый к тикеру GSAP (autoRaf: false, lagSmoothing(0))
src/lib/use-raf-loop.ts       rAF с паузой вне вьюпорта и при скрытой вкладке, дельта зажата с двух сторон
src/lib/telemetry.ts          мутируемая телеметрия кадра: ноль setState в кадре
src/three/hero-field.ts       два draw call: фоновый фрагментный шейдер + облако точек
src/components/               секции; ui/ — примитивы (Reveal, RevealWords, ScrambleText, MagneticButton, Cursor)
```

Ключевое решение по токенам: палитра уходит **и** в CSS, **и** в шейдер, **и** в canvas-частицы
из одного JSON. Графика физически не может разъехаться с палитрой интерфейса.

## Что анимируется

| Секция | Тип движения |
|---|---|
| 001 Манифест | две бесконечные ленты; скорость и `skewY` зависят от скорости скролла |
| 002 Протокол | pinned-контейнер + scrubbed-таймлайн, crossfade трёх фаз, слоистый reveal строк, рельс-навигация по фазам, глубина от курсора |
| 003 Техники | вертикальный скролл → горизонтальное движение, стрелки/клавиатура/колесо, счётчик |
| 004 Глубина | три слоя параллакса (28 % / 50 % / 72 %) + липкая легенда |
| 005 Шкала | двенадцать протоколов на одной оси: бары растут по скроллу, читалка следует за курсором и фокусом, маркер переезжает через `layoutId` |
| 006 Хроника | `useScroll` вместо GSAP: рельс заливается по прогрессу, фильтр «только возвраты» с layout-переходом |
| 007 Поле | canvas 2D: 3 режима, отталкивание курсором, импульс, честная метрика удержания |
| 008 Удержание | прямое взаимодействие: удержание указателя в полосе допуска, возвраты фиксируются как события |
| 009 Возражения | аккордеон на `grid-template-rows: 0fr → 1fr`, реакция на курсор тонкой линией |
| — | настройки движения и качества — модальное окно под шестернёй в шапке, не секция |

Анимируются только `transform` и `opacity`.

## Известные отклонения от кодека

- Reveal-анимации сделаны через `whileInView` (IntersectionObserver в Motion), а не через
  нативный `animation-timeline: view()`. Нативный вариант уходит с main-thread и остаётся
  ближайшим улучшением; нативный `scroll()` использован для полосы прогресса в шапке.
- DTCG поддержан частично: нет `$extensions`, композитных типов (`shadow`, `typography`)
  и наследования `$type` от группы.
- `AnimatePresence` используется только в модалке настроек; секции сознательно живут без
  exit-анимаций — на выходе из вьюпорта дешевле не анимировать вообще.
- Наклон ленты привязан к скорости скролла с потолком 1.1° и коэффициентом 0.09:
  обычное колесо даёт 0.3—0.6°, а не упирается в потолок на первом рывке.
- Основной чанк ~127 KB gzip (React + Motion). Переход на `motion/react-m` + `LazyMotion`
  снял бы около 25 KB.
