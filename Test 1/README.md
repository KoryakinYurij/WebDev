# MINDFIELD

Сайт об интенсивной практике внимания. Сделан как **тест подхода**: сначала из проверенных
репозиториев-референсов вытаскиваются только те решения, которые реально влияют на код,
и уже из них собирается проект. Не «вдохновлялся списком ссылок», а «прочитал правила,
применил, отклонившееся — задокументировал».

Задача страницы: медитация **без дыхательных таймеров и без интонации «расслабься»** —
кинетический, насыщенный скролл-опыт с интерактивом и несколькими видами скролл-анимации.

## Запуск

```bash
npm install
npm run dev        # генерация токенов + vite dev server
npm run typecheck  # tsc --noEmit
npm run build      # токены + typecheck + прод-сборка
npm run tokens     # validate + генерация токенов
npm run test:e2e   # Playwright: desktop/mobile/reduced/low-quality/геометрия/a11y
npm run og         # og.jpg 1200×630 + apple-touch-icon из тех же токенов (нужна сеть: гарнитуры Google Fonts)
npm run check      # build + bundle budget + e2e
```

`npm run check` — единственный гейт, который надо знать: он же запускается в CI
(`.github/workflows/check.yml`) на каждый push и pull request, с установкой chromium.

## Что откуда взято

Полный разбор решений с обоснованиями — в [`docs/DESIGN-CODEX.md`](docs/DESIGN-CODEX.md).
Коротко:

| Референс | Что взяли |
|---|---|
| `ai-web-design-codex` | правила scroll-driven опыта, бюджеты motion, перф-дисциплина, a11y |
| `design-tokens/community-group` | формат DTCG как источник правды по токенам |
| `awesome-design-systems` | слои «токены → примитивы → секции» |
| `motion-primitives` | магнитные кнопки, `layoutId`-переходы, spring-микровзаимодействия |
| `awesome-web-animation` | карта инструментов, эффект «расшифровки» текста, velocity-маркиза |
| `three.js` | один signature-момент: шейдерный фон + облако точек |
| `Front-End-Performance-Checklist`, `inclusive-design-checklist` | перф- и a11y-гейты |

Сознательно **не** взяли: Lottie (1400+ DOM-узлов на анимацию), anime.js (нет реактивного
жизненного цикла), mojs, ScrollMagic/Locomotive (legacy), постпроцессинг в WebGL
(полные проходы на кадр), «анимированные счётчики 0 → 150 243» (анти-паттерн из кодека).

## Архитектура

```
tokens/design.tokens.json     источник правды (DTCG)
scripts/build-tokens.mjs      без зависимостей → tokens.css (@theme для Tailwind v4) + tokens.ts
scripts/build-og.mjs          og.jpg 1200×630 + apple-touch-icon 180×180 из токенов
public/                       favicon.svg, og.jpg и apple-touch-icon.png (генерируются), robots.txt
src/generated/                ← генерируется, руками не править

src/styles/tokens.css         @theme: bg-*/text-*/font-*/ease-* утилиты появляются автоматически
src/lib/motion-config.tsx     MotionProvider: системный reduced-motion + ручной тумблер + качество
src/lib/smooth-scroll.tsx     Lenis, подключённый к тикеру GSAP (autoRaf: false, lagSmoothing(0))
src/lib/use-raf-loop.ts       rAF с паузой вне вьюпорта и при скрытой вкладке, дельта зажата с двух сторон
src/lib/telemetry.ts          мутируемая телеметрия кадра: ноль setState в кадре
src/three/hero-field.ts       два draw call: фоновый фрагментный шейдер + облако точек
src/components/               секции; ui/ — примитивы (Reveal, RevealWords, ScrambleText, MagneticButton, Cursor)
```

Прибор удержания показывается только в секции «Поле»: все три его величины считаются
именно там, а постоянное присутствие давало наложение на контент героя.

Ключевое решение по токенам: палитра уходит **и** в CSS, **и** в шейдер, **и** в canvas-частицы
из одного JSON. Графика физически не может разъехаться с палитрой интерфейса.

## Что анимируется

| Секция | Тип движения |
|---|---|
| 001 Манифест | две бесконечные ленты; скорость и `skewY` зависят от скорости скролла |
| 002 Протокол | полноэкранная «камера внимания»: большой canvas — главный субстрат, HUD-фаза поверх него, горизонтальная шкала 0–40 мин; шум сходится в объект → магентовые выбросы-возвраты → шум возвращается, объект остаётся |
| 003 Техники | вертикальный скролл → горизонтальное движение, стрелки/клавиатура/колесо, счётчик |
| 004 Глубина | три слоя параллакса (28 % / 50 % / 72 %) + липкая легенда |
| 005 Шкала | двенадцать протоколов на одной оси: бары растут по скроллу, читалка следует за курсором и фокусом, маркер переезжает через `layoutId` |
| 006 Хроника | canvas-осциллограмма: скролл проживает 40 минут и рисует линию удержания, провалы — возвраты; курсор раскрывает момент, драг перематывает сессию |
| 007 Поле | canvas 2D: 3 режима, отталкивание курсором, импульс, честная метрика удержания |
| 008 Шум | кинетическая типографика: скролл собирает фразу из разлетевшихся букв, курсор разгоняет их вокруг себя и отпускает обратно |
| 009 Возражения | табло вердиктов: подчёркивание дорисовывается скроллом, штамп «снято» от действия читателя, счётчик снятых; раскрытие — `grid-template-rows: 0fr → 1fr` |
| — | настройки движения и качества — модальное окно под шестернёй в шапке, не секция |

Анимируются только `transform` и `opacity`.

## Известные отклонения от кодека

- Reveal-анимации сделаны через `whileInView` (IntersectionObserver в Motion), а не через
  нативный `animation-timeline: view()`. Нативный вариант уходит с main-thread и остаётся
  ближайшим улучшением; нативный `scroll()` использован для полосы прогресса в шапке.
- DTCG core-значения используются для цветов/dimensions/durations; fluid CSS `clamp()` хранится как namespaced extension и имеет валидный core fallback.
- `AnimatePresence` используется только в модалке настроек; секции сознательно живут без
  exit-анимаций — на выходе из вьюпорта дешевле не анимировать вообще.
- Наклон ленты привязан к скорости скролла с потолком 1.1° и коэффициентом 0.09:
  обычное колесо даёт 0.3—0.6°, а не упирается в потолок на первом рывке.
- Размеры контролируются `npm run bundle:check`: потолок JS — 350 KB gzip, CSS — 30 KB.
- Появление контента в герое и шапке гейтится на `reduced` так же, как в `Reveal`. Без гейта
  посетитель с системным «меньше движения» ждал 0.5–0.6 с фейда, а axe валился через раз:
  снятый в момент фейда кадр давал контраст 2.68:1 на полупрозрачной кнопке вместо 4.5:1.
- Прибор удержания — только внутри секции «Поле»: вне неё все три его величины равны нулю,
  то есть прибор врал, а как `fixed`-панель в левом нижнем углу он наезжал на герой.
- Модалка настроек задаёт ширину числом (`max-w-[36rem]`), а не `max-w-xl`: именованные размеры
  ширины в проекте запрещены, потому что через `--spacing-*` они разрешаются в наши же
  clamp-токены (подробнее — в `docs/DESIGN-CODEX.md`).
- В «Протоколе» поле объектов существует от `md` только в режиме пина: после перехода к полноэкранной
  камере отдельной третьей колонки больше нет; при reduced-motion канвас не нужен (фазы стоят в потоке).
- Реакция букв в «Шуме» на курсор сделана смещением цели пружины, а не импульсом. Импульс в
  этой схеме неустойчив: равновесие наступает при смещении `импульс / жёсткость`, то есть буква
  вылетает за радиус отталкивания и болтается снаружи. У позиционного толчка есть потолок
  в 34 px, и с уходом курсора буква гарантированно возвращается в строку.
- Шапка анимирует `padding` при скролле, а не только transform/opacity. Проверено: заголовок
  `position: fixed`, поэтому пересчёт layout ограничен его поддеревом (~10 узлов), страница
  не переразмечается — иначе паддинг был бы заменён на transform.

## Что осталось на деплой

- `canonical` и `og:url` — абсолютные адреса: ссылка `href="/"` ломает сборку (Vite трактует
  `href` у `<link>` как ассет и падает на чтении каталога).
- `sitemap.xml` — в `robots.txt` уже стоит пометка, почему файла пока нет: `loc` в карте сайта
  обязан быть абсолютным, а выдуманный домен хуже отсутствия файла.
- `og:image` и `twitter:image` заданы относительными (`/og.jpg`) и разворачиваются краулером
  против адреса страницы — после домена их стоит заменить на абсолютные.
- Шрифты остаются на Google Fonts (preconnect стоит): self-host даёт и приватность, и
  стабильность метрик, но требует бинарных файлов и обновления лицензий — отложено сознательно.
