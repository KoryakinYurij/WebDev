# Контракт среды: prism-offline

Наблюдение 2026-09-14 в другой рабочей копии (Prism). Файл сохранён как история и как пример
контракта, а не как действующее описание текущей машины: см. `environments/freebuff-local.md`,
проверенный 2026-09-16. Не подставлять этот контракт в новые пакеты без повторной проверки
`python web-library/tools/probe_env.py.txt`.

Повторная проверка 2026-09-14 после следующих пользовательских ходов: созданное дерево сохранилось,
но конечный LF текстовых файлов исчез. Сборщик нормализует переводы строк и завершающий LF для
текстовых заданий и манифестов. Это не побайтовая гарантия и не основание изменять исходники
чужого сайта.

## Доступно

- Python 3, стандартная библиотека; установлены `tinycss2` и `yaml`.
- Deno 2.9.5: разбор локального JavaScript без пакетов.
- Чтение внешней документации через веб-инструмент агента.
- Многофайловые текстовые исходники и Python-сборка в один HTML.

## Недоступно

- `node`, `playwright`, Chromium, Chrome и Firefox не найдены в PATH; Python-модули playwright и
  selenium отсутствуют; в проверенных каталогах кэша браузер не обнаружен. Это ограниченный поиск,
  не доказательство отсутствия любой скрытой службы.
- HTTPS-запрос к GitHub из shell получал CONNECT 403. Веб-чтение не означает возможности `git clone`
  или скачивания npm-пакетов.
- Установка зависимостей и новых Python-окружений запрещена инструкциями той рабочей копии.
- Нет подтверждённого whitelist расширений: `.gitignore` отсутствовал.

## Правила

1. Писать только внутри workspace, относительными путями. Не менять `src/`, `Index.html.txt`,
   `build.py.txt` существующего сайта.
2. Новые исходники хранить в `.html.txt`, `.css.txt`, `.js.txt`, Python — `.py.txt`; не
   материализовать неподдерживаемые файлы в корне Prism.
3. Итог сайта — один HTML с включёнными стилями, скриптами и оригинальным inline SVG, без сети,
   серверной части и CDN при открытии.
4. Не использовать внешние фото, бинарные шрифты, base64-архивы и «временные» зависимости для обхода
   ограничений.
5. Не запускать обёртку или развёртку из `.agents/Scripts/` над всем текущим workspace: область
   действия определяется местом самого скрипта.
6. Не выдавать статический разбор, парсинг или моделирование DOM за просмотр браузером. При
   отсутствии браузера писать `not_run`, а не `pass`.

## Каталог сдачи

Результат писать только в `trial-output/<brief>-<arm>/`: модульные исходники в текстовых обёртках,
воспроизводимый `build.py.txt`, готовый `index.html.txt`, `README.md` с точными командами сборки и
экспорта, `REPORT.md` с направлением, проверками, ограничениями и временем.

Переход во внешнюю среду: скачать проект и сохранить обёртки как исходники. Вне Prism убрать
последний `.txt` только у готового HTML и открыть файл без сети. Массовое снятие `.txt` само по себе
не переписывает пути в сборщике и импорты.

Браузерные проверки доступны только после предоставления уже установленного браузера или
инструмента. PNG-превью в проект не добавлять: при наличии браузера использовать разрешённый
временный каталог и отдельно согласовать долговременное хранение доказательств.
