# Пробное чтение инструкции

2026-09-14. Метод: отдельный агент получил локальный скилл и готовый пакет fold-profile, но не диагнозы автора, отчёты и остальные брифы. Ему предложено описать выполнение первого скролл-задания и реакцию на запрос образовательного сайта с сохранением прогресса/дашбордом. Сайт не генерировался; это проверка понятности инструкции, не независимый A/B и не измерение дизайна.

## Что подтвердилось при чтении

- Понятны аудитория, обязательная фактура, главное действие, структура сдачи и отсутствие необходимости установки пакетов.
- Исполнитель различает статический анализ и невыполнимые здесь браузерные проверки.
- Запрос сохранения прогресса и дашборда требует уточнения/нового профиля, а не подстановки скролл-лендинга.

## Найдено и исправлено в v0.1

| Замечание | Изменение |
| --- | --- |
| Скилл велел пересобрать уже переданный пакет, хотя исполнитель не должен менять библиотеку | Добавлена ранняя развилка «собрать / исполнить готовый / исследовать неподдерживаемое» |
| Проверка неподдерживаемого типа стояла после команды сборки fold | Перенесена до маршрута первого теста |
| В списке сдачи не было README с экспортом, требуемого preserve-скиллом | README включён непосредственно в каждый пакет |
| Не определено взаимодействие ручной кнопки и прокрутки | В обоих брифах разделены ручное управление и скролл-представление |
| Ручное уменьшение движения не было явно задано в общем брифе | Добавлено одинаковое поле требований для всех вариантов сравнения |
| Упоминались карточки отложенных инструментов, отсутствующие в пакете | Пояснено, что они не являются входами первого задания и не должны устанавливаться |

## Неустранимое в этом ходе

Whitelist Prism не подтверждён, браузера в проверенной конфигурации нет, сохранность после следующей синхронизации ещё неизвестна. Исправление текста не устраняет эти ограничения.

Изменения проверены автором и машинной сборкой. Повторного независимого чтения исправленной версии и выполнения сайта ещё не было. Поэтому даже понятность окончательного пакета пока не считается полностью проверенной поведением исполнителя.
