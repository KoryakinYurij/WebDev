# Проверка библиотеки v0.1

Исторический отчёт первого захода, не текущая приёмка. После синхронизации обнаружена чувствительность манифестов к завершающему LF; см. [повторную проверку v0.2](review-v0.2.md).

Дата: 2026-09-14. Статус: **подготовлена для pilot; польза для качества сайтов ещё не измерена**.

## Выполнено

- Каталог: 12 карточек, 11 reviewed и 1 candidate. В выбранном профиле только 7 справок; сторонние runtime-библиотеки не установлены.
- Один профиль, два независимых модуля, два development-брифа. Третий закрытый бриф не создавался.
- Собраны три варианта fold: baseline — 785 слов, core — 1780, profile — 2884. Это подсчёт по пробелам, не токены модели. Ограничение 4500 слов — техническая страховка от разрастания, не оптимальный размер, подтверждённый экспериментом.
- Сборщик проверяет типы/обязательные поля, локальные пути, ID, зависимости, циклы/конфликты, статусы ресурсов, бюджет, SHA-256 и согласованность созданных пакетов.
- 22 положительных и отрицательных контрольных случая прошли; результат: [tool-checks.json](tool-checks.json). Включены отклонение неизвестного профиля/среды/возможности, candidate в активном наборе и tested без файла доказательства. Контрольные случаи выполнены в памяти; постоянный отдельный тестовый набор пока не добавлен.
- Встроенный quick_validate для скилла прошёл. Это проверка формата, не доказательство поведения агента.
- Пробное чтение выявило неоднозначности; они исправлены, см. [instruction-walkthrough.md](instruction-walkthrough.md). Реализация сайта не проверялась.
- SHA-256 семи файлов прежнего сайта совпали с исходно прочитанными. В корневой README добавлена только ссылка на библиотеку.

## Отдельно: существующий сайт

[Статический аудит](local-audit.json): 8 pass, 1 fail, 7 not_run. Fail относится к строгому совпадению экспорта и сборки: разные переводы строк и два пустых ряда; непустые строки совпадают. Этот факт не исправлялся и не считается визуальным дефектом. Подробнее: [preflight.md](preflight.md).

## Не выполнено

Генерация сайтов для A/B, запуск в браузере, скриншоты, реальные пользовательские сценарии, performance-замеры, human design review, оценка эффективности источников и проверка после будущей синхронизации Prism. Ни один внешний ресурс не повышен до tested/recommended.

## Повторяемые команды

```sh
python web-library/tools/library.py.txt validate
python web-library/tools/audit_local.py.txt
```

Первая проверяет библиотеку и текущие пакеты. Вторая — прежний сайт и ожидаемо возвращает код 1, пока сохраняется описанное расхождение экспорта; не исправлять его автоматически в задаче библиотеки. После изменений источников сначала пересобрать пакеты командами из START. 22 контрольных случая — снимок проверки данной версии, а не утверждение, что эти две команды повторяют все отрицательные сценарии.
