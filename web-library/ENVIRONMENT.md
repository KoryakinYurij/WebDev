# Контракт среды: prism-offline

Наблюдение 2026-09-14, а не вечная характеристика Prism. Перед новым запуском перепроверить.

Повторная проверка 2026-09-14 после следующих пользовательских ходов: созданное дерево сохранилось, но конечный LF текстовых файлов исчез. В v0.2 сборщик нормализует переводы строк и завершающий LF для текстовых заданий/манифестов. Это не побайтовая гарантия и не основание изменять исходники чужого сайта. Следующую синхронизацию проверять снова.

## Доступно и проверено

- Python 3, стандартная библиотека; установлены `tinycss2` и `yaml`.
- Deno 2.9.5; можно разбирать локальный JavaScript без пакетов.
- Чтение внешней документации через веб-инструмент агента.
- Многофайловые текстовые исходники и Python-сборка в один HTML.

## Не доступно в проверенной конфигурации

- `node`, `playwright`, Chromium, Chrome и Firefox не найдены в PATH; Python-модули playwright/selenium отсутствуют. В проверенных каталогах кэша браузер не обнаружен. Это ограниченный поиск, не доказательство отсутствия любой скрытой службы.
- HTTPS-запрос к GitHub из shell получает CONNECT 403. Веб-чтение не означает возможности git clone или скачивания npm-пакетов.
- Установка зависимостей и новых Python-окружений запрещена инструкциями workspace.
- Нет подтверждённого whitelist расширений: `.gitignore` отсутствует.

## Обязательные правила первого теста

1. Писать только внутри workspace, используя относительные пути. Не менять `src/`, `Index.html.txt`, `build.py.txt` существующего сайта.
2. Новые исходники хранить в `.html.txt`, `.css.txt`, `.js.txt`, Python — `.py.txt`; не материализовать неподдерживаемые файлы в корне Prism.
3. Итог сайта — один HTML с включёнными стилями, скриптами и оригинальным inline SVG. Без сети, серверной части и CDN при открытии.
4. Не использовать внешние фото, бинарные шрифты, base64-архивы или «временные» зависимости для обхода ограничений.
5. Не запускать обёртку/развёртку из `.agents/Scripts/` над всем текущим workspace: область действия определяется местом самого скрипта. Для теста существующая схема имён уже подходит.
6. Не выдавать статический разбор, парсинг или моделирование DOM за просмотр браузером. При отсутствии браузера писать `not_run`, а не `pass`.

## Переход во внешнюю среду

Скачать проект и сохранить обёртки как исходники. Вне Prism убрать последний `.txt` только у готового HTML и открыть файл без сети. Для разработки разрешено оставить исходные обёртки и выполнять Python-сборщик. Если переименованы сами исходники, обновить пути сборщика; массовое снятие `.txt` само по себе не переписывает импорты.

Браузерные проверки доступны только после предоставления уже установленного браузера/инструмента. Проверять готовый экспорт, не только dev-server. PNG-превью в проект не добавлять; при наличии браузера использовать разрешённый временный каталог для просмотра и отдельно согласовать долговременное хранение доказательств.
