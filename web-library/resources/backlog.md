# Отложенные кандидаты, не рекомендации

Это сохранение исходного списка пользователя, не результат проверки перечисленных репозиториев. Не загружать этот файл в первый пакет. Не выбирать инструмент автоматически по описанию в исходном ресерче.

| Кандидат | Когда возвращаться |
| --- | --- |
| https://github.com/sergey-pimenov/awesome-web-animation | Когда известен конкретный тип движения и не найден подходящий механизм |
| https://github.com/mrdoob/three.js | Когда задача требует настоящей 3D-сцены, а не эффекта ради эффекта |
| https://github.com/airbnb/lottie-web | Когда предоставлены исходные анимационные материалы и нужен их проигрыватель |
| https://github.com/mojs/mojs | Когда обоснованы векторные частицы/сложные эффекты |
| https://github.com/murderszn/motion | Когда нужна генеративная графика; сначала проверить сам проект и реальные возможности |
| https://github.com/mattdesl/canvas-sketch | Когда алгоритмическая графика решает задачу материала |
| https://github.com/sjfricke/awesome-webgl | Навигация при подтверждённой потребности WebGL |
| https://github.com/madebymustafa/inclusive-design-checklist | При расширении аудитории/устройств и процесса доступности |
| https://github.com/bendc/frontend-guidelines | При конкретном пробеле соглашений frontend-кода |
| https://github.com/bansi-chapani/universal-website-generator | Сравнить процесс после получения содержимого; числа проверок из ресерча не подтверждены |
| https://github.com/o-stahl/osw-studio | Если потребуется собственный конструктор, не для первого сайта |
| https://github.com/design-tokens/community-group | Когда нужен обмен токенами; не называть внутренний JSON DTCG-совместимым без проверки |

У каждого здесь статус `unreviewed`. При возврате открыть первичные источники, уточнить назначение и ограничения, затем создать полноценную карточку. Не считать дату создания этого списка датой проверки URL.
