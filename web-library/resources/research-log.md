# Журнал исследования — 2026-09-14

История первого захода v0.1. Актуальные решения после углублённой проверки: [ресерч v0.2](research-v0.2.md). Две карточки гайдов из первоначального набора теперь retired; текущие статусы смотреть в catalog.json.

## Границы достоверности

Карточки в `web-library/resources/catalog.json` — единственный структурированный реестр внешних источников. `reviewed` означает прочитанный документ в указанном объёме, НЕ установленную библиотеку, проверенный компонент или доказанную пользу. `candidate` в автоматический пакет не включается. В этом заходе нет ресурсов со статусом `tested` или `recommended`.

Страницы прочитаны через веб-инструмент. git/curl из shell к GitHub получает 403. Ни один внешний репозиторий не склонирован; immutable commit SHA не зафиксирован. Дата чтения не называется версией релиза или датой последнего обновления. Перед исполнением стороннего кода нужна отдельная проверка конкретной версии и условий использования.

## Что привело к решениям

| Источник | Проверенный объём | Наше решение |
| --- | --- | --- |
| MDN scroll-driven animations | Модель timeline и примеры | CSS — кандидат enhancement, не единственный обязательный механизм |
| MDN IntersectionObserver | Пороги, callback, ограничения точности | Для появления, не для точного непрерывного scrub |
| MDN prefers-reduced-motion | Назначение настройки | Проверять её до эффектов и во время работы |
| W3C Contrast/Reflow | Пороги и условия соответствующих SC | Добавить конкретные проверки, не обещать весь WCAG |
| ai-web-design-codex | README, scroll-driven-experiences, typography-systems, layout-grids-and-spacing | Загружать выбранные файлы по потребности, не все 60 гайдов |
| GSAP | Официальная страница ScrollTrigger, README репозитория | Оставить условным кандидатом вне первого runtime-стека |
| Playwright | Visual comparisons | Будущая браузерная проверка; сейчас честный not_run |
| awesome-design-systems | Теги и индекс | Источник дальнейшего поиска, не визуальный референс сам по себе |
| Performance Checklist | Раздел JavaScript | Необходимость зависимостей и замеры; не копировать все советы доставки |
| motion-primitives | Страница репозитория | Недостаточно для интеграции; оставить candidate |

Точная ссылка на каждый выбранный документ хранится в карточке. Дополнительно просмотрен файл компоновки: https://github.com/Eneryleen/ai-web-design-codex/blob/main/00-foundations/layout-grids-and-spacing.md . Страница motion-primitives docs и запрос universal-website-generator не дали достаточного материала; это не доказательство, что проект не существует.

## Не доказано

Нет визуального сравнения с референсами, подтверждения «профессионального уровня» внешних репозиториев, проверки всех лицензий, запуска сторонних примеров, performance-замеров или исследования причин предыдущих неудачных сайтов. Из локального проекта извлечены гипотезы и воспроизводимые статические факты; старые заявления README о симуляциях не переименованы в наши новые результаты.

Не импортирован чужой код и не скопированы полные руководства. Библиотека содержит собственный процесс, краткие карточки и ссылки. Ресурс считается полезным только после сопоставимого эксперимента; число ссылок не метрика успеха.
