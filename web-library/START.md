# Веб-библиотека: первый проверяемый заход

Версия 0.2, 14 сентября 2026. Это рабочая гипотеза, не обещание senior-качества за два запроса.

## Начать здесь

Первый тест — **«Линия сгиба»**, вымышленная мастерская бумажных объектов. Один автономный скролл-сайт, без установки зависимостей, CDN, внешних шрифтов и фотографий. Это сознательно узкий эксперимент, не универсальный стек. Существующая «Тишина внутри» не изменяется и не назначается визуальным эталоном.

Готовое задание: [пакет первого профиля](packets/fold-profile.md). Передать его новому агенту в отдельной рабочей копии. Не передавать ему другие варианты, отчёты и исходники старого сайта: иначе сравнение будет загрязнено. При отсутствии нового сеанса можно сделать демонстрацию здесь, но не называть её независимым экспериментом.

Короткая команда для будущего запуска:

> Выполни задание из `web-library/packets/fold-profile.md`. Не меняй существующий сайт и библиотеку. Сохрани новый результат в указанном в пакете каталоге. Выполни доступные проверки и явно перечисли недоступные. Если пакет противоречит действующим правилам среды, соблюдай правила среды и запиши ограничение.

## Команды из корня workspace

```sh
python web-library/tools/library.py.txt validate
python web-library/tools/library.py.txt selfcheck
python web-library/tools/library.py.txt check-run --report web-library/experiments/run-template.json
python web-library/tools/library.py.txt assemble --brief web-library/experiments/briefs/fold.json --arm baseline
python web-library/tools/library.py.txt assemble --brief web-library/experiments/briefs/fold.json --arm core
python web-library/tools/library.py.txt assemble --brief web-library/experiments/briefs/fold.json --arm profile
python web-library/tools/audit_local.py.txt
```

Сборщик пакета работает без сети, ничего не устанавливает и не запускает агента. Он выбирает известные модули по структурированному брифу; это не свободный AI-поиск. Неподдерживаемую возможность он отклоняет, а не выдаёт за реализованную.

Результат сборщика — Markdown-задание и JSON-манифест v2 с текстовыми SHA-256 входов, причиной выбора и пропусками проверки. CRLF/CR нормализуются в LF, завершающий перевод строки — в один LF: синхронизация Prism уже удаляла последний LF. Внутренние строки и пробелы не игнорируются. Это не побайтовая подпись экспортированного сайта. Сгенерированные пакеты не редактировать вручную.

После изменения исходников выполнить validate --sources-only, пересобрать три варианта и выполнить полный validate. --sources-only не подтверждает свежесть готовых пакетов и не читает содержание reports при проверке ссылок. selfcheck воспроизводит положительные и отрицательные сценарии, включая преобразования Prism. check-run проверяет структуру и наличие файлов доказательств отчёта, но не их истинность. Манифест — контроль изменений, не архив; перед реальным сравнением сохранить отдельную копию всего набора.

## Скилл и сохранность

Локальный скилл находится в `.agents/skills/assemble-web-trial/SKILL.md`. Его можно прочитать вручную; автоматическое обнаружение новым сеансом здесь не проверено.

В workspace отсутствует `.gitignore`, поэтому whitelist Prism не подтверждён. Использованы существующие здесь форматы `.md`, `.json`, `.yaml` и текстовые оболочки `.py.txt`. В повторном ходе файлы найдены, но это не гарантия будущей сохранности: перед новой работой проверить дерево и validate. Правила фильтра не менялись.

После скачивания `library.py.txt` можно переименовать в `library.py`, а `audit_local.py.txt` — в `audit_local.py`. Скрипты запускаются Python и с исходным суффиксом; для приведённых команд переименование не требуется. Сохранять структуру каталогов. Новый сайт при выполнении теста должен экспортироваться как `index.html.txt`; удалить последнее `.txt` и открывать `index.html` вне Prism. Сам сайт в этом заходе ещё не генерировался.

Если переименован инструмент, заменить его имя в команде и пересобрать пакеты: в манифесте фиксируется и путь сборщика. Форматы данных, брифы и документацию не переименовывать. selfcheck поддерживает оба имени Python-инструментов.

## Чего пока нет

Нет браузерного запуска сайтов A/B, скриншотов, оценок пользователя, подтверждения полезности модулей или гарантии результата за 1–2 запроса. Третий закрытый бриф намеренно не создан: его должен составить оценщик после фиксации версии, не показывая настройщику библиотеки заранее.
