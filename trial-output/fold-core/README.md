# Линия сгиба — arm A (`core`)

Одна автономная страница по брифу `fold` без профиля и модулей: только общее ядро и проверки.
Направление — инструкционный лист мастерской. Ни одной зависимости, ни одного сетевого запроса,
системные шрифты, оригинальные inline SVG.

## Запуск

```sh
cd "trial-output/fold-core"
node build.mjs                 # собрать dist/index.html одним файлом
node checks/verify.mjs         # 31 проверка в Chromium, отчёт в checks/report.txt
```

Открыть результат: `dist/index.html` двойным щелчком или `index.html` из каталога проекта —
оба варианта работают по `file://` без сервера, потому что скрипт подключён как обычный,
а не как модуль.

Проверки берут браузер из уже установленного Playwright в `Test 1/node_modules`; ничего
не устанавливается и не скачивается. Снимки пишутся в `evidence/`.

## Состав

| Файл | Роль |
| --- | --- |
| `index.html` | вся разметка и содержание; четыре inline SVG; якоря и подписи |
| `styles.css` | токены, одна колонка, состояния сцены, режимы движения |
| `main.js` | прогрессивное улучшение: режим движения, подчёркивание кадра, схема сгиба |
| `build.mjs` | сборка автономного `dist/index.html` (стандартная библиотека Node) |
| `checks/verify.mjs` | статические и браузерные проверки, отчёт `checks/report.txt` |
| `STEPS.md` | хронология решений и правок |
| `REPORT.md` | направление, статусы `T01–T12`, что не проверено |
| `dist/index.html` | результат сборки (генерируется) |
| `evidence/` | снимки из проверок (генерируются) |

## Состояния страницы

- **Без скриптов.** Весь рассказ, навигация и главное действие работают; три состояния листа
  показаны тремя статическими рисунками; схема стоит в плоском положении и объяснена текстом;
  оба переключателя скрыты в разметке.
- **Скрипты, обычное движение.** На узком экране текущий кадр подчёркивается по прокрутке
  (в обе стороны), на широком все три равнозначны: в один ряд «текущего» не существует.
  Кнопка управляет положением схемы, прокрутка ручной выбор не меняет.
- **Уменьшенное движение.** Эффективное уменьшение = системная настройка ИЛИ ручной переключатель.
  Подчёркивание выключено, переходы сведены к нулю, схема переключается мгновенно, прокрутка
  остаётся нативной. При системной настройке переключатель не действует и объясняет это.

## Правки

- Содержание и структура — `index.html`; текст брифа использован дословно.
- Токены, сетка, режимы движения — `styles.css`.
- Поведение — `main.js`; проверки опираются на классы и атрибуты, а не на текст.
- После любой правки исходников: `node build.mjs && node checks/verify.mjs`.
  Проверка «готовый экспорт соответствует сборке» намеренно падает, если `dist` устарел.
