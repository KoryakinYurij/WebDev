# arm B (`fold-profile`) — «Линия сгиба» под профилем скролл-истории

Пилотный запуск по пакету `web-library/packets/fold-profile.md` в среде `freebuff-local`.
Это тот же бриф, что в arm A, но с профилем `scroll-story` и модулями `visual-direction` /
`scroll-motion`: закреплённая сцена обязательна, направление фиксируется до кода, сдаётся
объяснение выбора.

## Что это

Статический документ: семантическая разметка, CSS, около 300 строк JavaScript, оригинальные inline
SVG. Никаких библиотек, шрифтов и изображений из сети. Один автономный файл `dist/index.html`
открывается по `file://`.

Сцена: лист на столе. Прокрутка задаёт угол сгиба — от плоскости (0°) через вертикаль (86°) до
сложенного листа (172°). Рядом с листом стоит рассказ из трёх стадий; светлая половина листа и
подсветка показывают, что он делает. Узкий экран и режим уменьшенного движения вместо сцены
показывают три статических кадра, отметив тот, на котором остановилось чтение.

## Файлы

| Файл | Что внутри |
| --- | --- |
| `index.html` | разметка, содержание брифа дословно, сцена из пяти слоёв, три кадра SVG |
| `styles.css` | токены, статическая раскладка, закреплённая раскладка, режимы движения |
| `main.js` | прогресс, угол, стадии, режимы движения, сохранение места чтения |
| `build.mjs` | сборка автономного `dist/index.html` |
| `checks/verify.mjs` | 40 проверок: разметка, поведение, клавиатура, доступность, экспорт |
| `checks/audits/` | средства просмотра: что в кадре, какой слой нарисован, снимки до/после |
| `evidence/` | снимки проверок, вывод двух прогонов, текстовые разборы снимков |
| `STEPS.md` | журнал шагов и реестр дефектов |
| `REPORT.md` | отчёт: что сдано, направление, проверки, ограничения |

## Воспроизведение

```bash
cd trial-output/fold-profile
node build.mjs            # собрать dist/index.html
node checks/verify.mjs    # 40 проверок, вывод построчно, код возврата 1 при провале
```

Playwright берётся из соседнего `Test 1/node_modules` — отдельной установки не требует.

Просмотр снимков без графического интерфейса:

```bash
python ../../web-library/tools/png_text.py.txt evidence/01-scene-end.png --width 108 --rows 34
python ../../web-library/tools/png_text.py.txt evidence/fold-after.png --mean 251,443,426,282
```

Что именно проверяет каждая проверка, видно из её имени в выводе; подробности и история правок —
в `STEPS.md`.
